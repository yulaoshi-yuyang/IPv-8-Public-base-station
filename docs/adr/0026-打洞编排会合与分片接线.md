# ADR 0026 — 打洞编排、会合（Rendezvous）与流级分片接线

> 是什么：级 2 NAT 打洞全链路编排（Resolver 登记/会合/敲门撞洞）、打洞不成的级 3 中继退路、Established 后流级分片在节点侧的接线与生命周期。
> 证据来源：src/adapter/wintun-node/src/main.rs:224-226、362-364、431-432、1114-1115、1170-1175、1596-1598、1758-1760、2239-2279；src/cloud/resolver/src/lib.rs:46-52、60-66、75-84、122-126、242-245、318-325；shared/ipv8-proto/resolver.proto:16-18、53-58；src/tools/ws-node/src/main.rs:11-13、253-256；scripts/punch-smoke.ps1:1-3；scripts/relay-smoke.ps1:1-3。
> 抽取日期：2026-10-13（自代码注释抽取，债 1）。

## 背景

对端无固定公网入口（双方都在 NAT 后）时，静态 --peer-ip 直连不可用：
需要一个会合方观察双方真实出口映射并撮合；打洞不成还需要退路。同一决策
族还裁定：隧道建立后，Data 面流级分片（ADR-0024 机制）在节点侧如何
接管、暂停与退役。

## 决定了什么

1. **级 2 打洞 = Resolver 会合**：节点向 Resolver 登记（PoP 鉴权）并周期
   会合；服务端记录"在该连接上看到的源地址"（observed，STUN 语义），返回
   对端候选（observed 排首位）；发起方向候选连发敲门包撞活双方 NAT 映射，
   Init 目标改指首选候选，握手由既有主循环幂等重发驱动，应答方
   --learn-peer 现学回程地址（resolver.proto:16-18、main.rs:1170-1175）。
2. 敲门包**无语义**（8 字节魔数 "IP8PUNCH"）：仅作撞活 NAT 映射之用，
   收侧在进引擎解析前静默吸收，不污染 dropped 计数判据（main.rs:224-226）。
3. observed 的信任与新鲜度规则：
   - 权威候选是 observed；节点自报候选仅信息性（可能伪冒），入口消毒
     （≤8 条、单条 ≤64B）（lib.rs:50-52、82-84）。
   - observed 独立新鲜度窗口 90s（UDP NAT 空闲超时典型 30s~2min），超窗
     不作候选，节点心跳刷新（20s 周期，1:4.5 安全比）（lib.rs:75-78、main.rs:1175）。
   - 会合窗口：双方调用须在窗口内互相看见，否则返回无候选，退回
     直连/中继判断（lib.rs:79-81）。
   - observed 不可观察（None）时：同身份重登记保留旧值，新身份接管则
     清空——旧映射属于上一个持有者，不能继承（lib.rs:242-245、318-325）。
   - 匿名者拿不到 observed：鉴权 = 已登记身份验 PoP（ADR-007 收紧）
     （resolver.proto:18）。
4. PoP 域分离：登记与会合用不同签名域（ipv8plus-resolve /
   ipv8plus-rendezvous），登记签名不可挪用来发起会合，反之亦然
   （lib.rs:122-126）。
5. 打洞不成的退路 = **级 3 中继**：ws-node relay 模式（双向多会话中继，
   零信任密文搬运，无需身份种子只信 CA；注册帧 RPT0 = addr+cert）
   （ws-node/main.rs:11-13、253-256；relay-smoke.ps1：A/B 永不直连，
   每帧过中继表查找）。
6. 流级分片节点接线：Established 后主循环装填 ShardHub（--shards 1..=64，
   默认 1 永不启用零回归）；分片活跃时入站 Data 帧由 workers 接管（同余
   路由免解密定片），握手/控制帧仍走引擎；出站批投 workers（锁外并行
   封装，帧经出口线程异步发出）；分片活跃期多路径复制/FEC 同步暂停
   （Phase 4 spec 决议）；隧道重协商 → 旧分片退役，下 tick 按新密钥重组
   （main.rs:1114-1115、1596-1598、1758-1760、2239-2279）。

# 立项书

## 一句话定位

IPv8+ 是面向广域网的加密叠加网络协议——端到端加密、低延迟数据面、可编程流量判决，让未修改的应用经 wintun 透明跑在安全隧道上。

## v1 做什么（前三个功能，写死）

1. **加密隧道**：X25519 握手 + ChaCha20-Poly1305/AES-GCM AEAD，防重放，证书认证
2. **透明接入**：wintun 虚拟网卡，未修改应用的 IPv4/IPv6 流量自动走隧道
3. **可编程钩子**：出站/入站数据包可由外部程序判决（放行/丢弃/修改/延迟/镜像/限速）

## v1 不做什么（负面清单）

- 不做内核态数据面（数据面永不下沉内核，驱动只做管道）
- 不做 IPv4 线级兼容（走叠加层，不修改网络层协议）
- 不对接 IETF draft-thain-ipv8（两者技术路线无关）
- 不做 IPv6 替代（仅承载，不替换）
- 不做 GUI 客户端（命令行 + 服务化为主）

## 第一个里程碑

- 输入：两台 Windows 机器，安装 wintun + ipv8-node
- 输出：`ping` 对端 IPv8 地址通，应用流量经加密隧道传输
- 怎样算活了：双机 ping 通 + 抓包确认 UDP 载荷为 AEAD 密文 + 钩子能拦截数据包

## 限高令

超出以下范围的功能进 parking-lot，v1 交付后再审批：
- 多路径竞速、FEC（v1.5）
- 邻居发现 L2 承载（P8）
- Windows 服务化（P9）
- 驱动 Attestation 签名（P7b，需 EV 证书）
- 移动端支持
- 可视化拓扑 UI
